# MindSphere 3D — كرة العقل

A futuristic 3D puzzle and spatial cognition training web game built with React, Three.js, TypeScript, and Recharts.

## Features

- **3D Chambers & Puzzles**: 15 playable chambers across 3 themed futuristic environments (The Neon Laboratory, The Crystal Temple, and The Quantum Vault).
- **Diverse Logic Mechanics**: Concentric ring rotations, interconnected switch logic networks, numeric and geometric sequences, pattern matrices, terminal deduction puzzles, and the grand 3D gyroscope core paradox.
- **Three.js WebGL Engine**: 3D chamber environment with hydraulic blast doors, glowing particle field, dynamic pedestal lighting, and orbital camera controls (drag to orbit, pinch to zoom, and raycasting interactions).
- **Intelligence Analytics**: Interactive Recharts visualization tracking cognitive performance and Intelligence Points over the player's last 10 chambers, featuring peak, average, and completion KPI metrics.
- **Time Attack & Global Leaderboard**: High-stakes countdown mode with time bonus multipliers and simulated global competitive rankings.
- **3-Tier Neural Guidance System**: Tiered clues (Gentle Insight ➔ Directional Logic ➔ Core Solution Step) for each chamber.
- **Bilingual Support**: Full Arabic and English localization with native RTL / LTR layout switching.
- **Procedural Audio Synthesizer**: Web Audio API sound synthesis with haptic feedback, custom sfx, and ambient soundscapes.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **3D Graphics**: Three.js
- **Data Visualization**: Recharts
- **Icons & Styling**: Custom futuristic CSS & Lucide React

## Running Locally

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to play.
